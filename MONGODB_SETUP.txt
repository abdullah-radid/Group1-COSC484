MongoDB backend setup

1. Make sure MongoDB is running locally, or use a MongoDB Atlas connection string.

2. Local MongoDB default used by this project:
   mongodb://127.0.0.1:27017/towson_apartments

3. To use a different database connection:
   Windows cmd:
   set MONGO_URI=your_connection_string && npm start

   PowerShell:
   $env:MONGO_URI="your_connection_string"; npm start

4. Start the project:
   npm install
   npm start

5. Starter login accounts are created automatically the first time MongoDB connects:
   Resident: resident@test.com / password123
   Maintenance: employee ID 1001 / password123
   Admin: employee ID 9001 / password123 / admin code 1234
